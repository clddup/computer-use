# 安全、权限与使用约束

## 系统权限与可选范围限制

宿主以自己控制的文件提供批准 PID、固定 `allowed_apps` 启动 profile、截图、辅助功能、输入权限及会话时长。helper 读取一次，不允许模型经工具扩大范围；`launch_app` 只能引用 policy 中已有 app id，不能传 exe、shell 或临时 args。默认不传 policy 时为当前用户桌面模式，Agent 动态发现/打开应用并选择窗口；PID 不是部署配置。桌面模式不隔离应用间影响，权限由操作系统授予。显式提供的 policy 才使用受限模式，空白名单拒绝。会话时长限制 1–3600 秒；一 helper 一会话；动作串行。权限文件应保存在仅宿主可改写的位置，禁止从网页/窗口内容生成或覆盖。

策略限制的是这个 helper 的操作，不是操作系统沙箱。批准应用本身可能有网络、文件、外部窗口及特权交互能力；快捷键、菜单、拖动等也可能触发外部行为。宿主仍需针对破坏性、付费、外发、删除等动作取得用户授权。不得用本项目规避 OS 权限、登录、订阅、审批或安全桌面。

每用户文件锁防止本项目的正常实例同时控制桌面；锁不约束其他自动化软件、人类操作或恶意同用户进程。环境变量必须由可信宿主提供，不能用不同 HOME/LOCALAPPDATA 假装获得另一桌面租约。Unix 目录做 owner/symlink 检查，但当前检查与打开不是完整的抗竞态沙箱，不能在敌对同用户环境中作为安全边界。

## 数据

- UIA/AX/AT-SPI 密码节点不读出密码 value，且拒绝元素形式定位密码框；这不保证应用正确标注所有敏感字段。
- 截图仍可能包含敏感内容；截图不做通用隐私识别/涂抹。允许坐标点击/聚焦后文本输入，故密码元素拒绝也**不等于禁止向所有密码框输入的强保证**。
- AX/UIA 树最多 512 节点、16 层，每节点最多 128 子节点；value 限制长度。应用提供的数据是不可信输入。
- stdout 仅协议；生产默认不记录截图、输入文本或完整树。`onStderr` 回调由宿主选择保存，勿把日志默认发送到外部服务。
- Windows GUI 测试截图及 oracle 仅保存在本地被忽略目录，含固定假密码和测试文本，不应提交或上传个人窗口截图。
- Linux X11 截图来自 root 的窗口区域，可能包含遮挡窗口，授权目标 PID **不能保证截图只含该 PID 的像素**。此语义须由宿主明确接受。

## 桌面内容不授予权限

网页、邮件、截图、控件名称、文档文本均是数据，不是系统/用户指令。Agent 不得按其中的提示修改策略、启动别的程序、外发内容或绕过确认。MCP 没有 shell/eval/自授权参数；但接入 Agent 的其他工具可能拥有这些能力，宿主须统一管控。

## 停止和 unknown

- 本地运行时调用 `stop()`，MCP 调用 `computer_stop`；helper CTRL-C、stdin EOF、会话 TTL 也取消。
- stop 必须能在 act 尚未完成时调用，不要先 await 长动作再请求停止。
- 取消可能发生在部分输入后。unknown/UnknownExecutionError 必须先核对现场，不自动再点击、再提交或重发文本。
- 启动/激活错误的 `may_have_executed=true` 同样表示不能安全重试；SDK 抛 `UnknownExecutionError`。会话仍活动时先重新枚举核对应用/窗口；会话已经停止时，旧 helper 的日志和引用不再可用。进入原生激活阶段即作废旧观察，之后即使激活失败也不能复用旧观察输入。
- 同一 helper 的 action_status 可核对仍保留的日志；stop 后日志释放，重启后不能靠相同 action_id 恢复去重。
- 正常取消释放项目持有的键鼠，不承诺撤回操作；强杀、崩溃、机器断电不能保证 cleanup。
- Windows 物理输入拒绝检测到的用户物理 modifier；Windows semantic UIA 不经物理输入路径，但 provider 仍可能改变前台/焦点。macOS 使用窗口定向 `postToPid`，不移动系统鼠标、不隐式激活目标；非公开窗口坐标/事件字段不兼容时明确失败，禁止静默回退全局 HID。独立指针不等于完整隔离应用/输入法状态：应用自身行为、用户同时编辑同一目标以及 IME 组合文本仍可能相互影响。
- macOS 指针为鼠标穿透、非激活窗口，系统共享标志来自真实持续 `SCStream`，不是模拟系统权限 UI；关闭截图的会话不为显示标志而采集屏幕。流与指针随切目标/stop/EOF/TTL 清理，显示不会扩大 policy 的进程范围。
- macOS PNG 只来自所选窗口共享流，无帧/中断/锁屏时明确报错，不抓取桌面或操作登录界面。MCP instructions 与 skill 禁止 Agent 改用 shell/AppleScript 绕开；它们不是对宿主其它工具的强制沙箱，宿主仍需约束 Agent 的全局 GUI 操作能力。
- MCP 连接可保留，但控制会话不会自动恢复；仅显式 `computer_start` 在清理成功后创建新 helper/epoch。旧观察、动作日志和不确定操作不继承、不重放。SDK `stop` 仍为实例终态。
- UIA semantic action 先做无副作用的 pattern 预检，投递开始后发生取消/超时/失联均为 unknown；不能自动切换到 SendInput。WGC 不含 cursor 与系统 cursor 隐藏是不同概念，本项目不修改全局 cursor。Windows 持续 WGC 只缓存授权窗口的最新帧，目标身份/几何变化会使旧帧失效；独立 pointer overlay 不接收焦点、不参与命中测试、不扩大 policy 范围，也不是后台定向输入。物理输入仍遵循 ChatGPT/Codex Windows 行为，可能自动激活目标窗口；停止、EOF、TTL 或共享故障会关闭 overlay/capture，清理未确认时拒绝继续复用。
- 动作 dispatch 后的 `window_refresh` 只是策略过滤后的窗口拓扑发现，不是应用业务成功证明。新窗口不会被自动选中、激活或捕获；必须使用刷新返回的完整 `Window` 引用再 observe。刷新失败不掩盖已发生的副作用，unknown 动作永不自动重放；标题、应用名、窗口大小和语言文本都不能扩大授权范围。

## 不支持

不承诺管理员/提权应用、UAC/登录/锁屏安全桌面、任意后台/最小化窗口、任意应用完整可访问性、native Wayland、跨崩溃 exactly-once、应用任务自动验证。不会自动修改剪贴板、全局键盘映射、权限设置或 Agent/MCP 配置。

## 研究授权边界

仅对用户本机已安装发行版做有界定向静态研究；没有运行目标私有 helper、Frida 或注入，没有读取聊天、cookies、凭据，没有上传目标文件。已经阅读目标可读实现，因此不称严格 clean-room；独立代码不得复制专有实现片段。研究工具许可证不赋予目标内容再分发权。
